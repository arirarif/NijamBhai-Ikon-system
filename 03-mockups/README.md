## Build order (recommended)
1. `_shared.css` — design system (colors, type, spacing, components)
2. `01-dashboard.html` — most important, sets the visual tone
3. `02-companies.html` — entry point for all new work
4. `04-order-detail.html` — the core screen
5. Remaining screens after these three are approved
